# Kain't Decide?

Hungry but can't pick what to cook? **Kain't Decide?** is a recipe website that helps you discover easy, delicious meals for whatever you're craving — no more endless scrolling through recipe blogs.

👉 **[Visit the website here](https://rjced.github.io/Kaint-Decide/)** 👈

## What you can do

- 🔍 **Search** for dishes and cuisines instantly
- 📂 **Browse** recipes organized by category
- 🔖 **Bookmark** your favorite recipes to revisit later
- 📱 Enjoy a clean, mobile-friendly experience

## About

Kain't Decide? was built to make finding your next meal simple and enjoyable. Whether you're cooking for yourself or planning something special, you'll find a recipe that fits.

Built with plain **HTML, CSS, and JavaScript**.
